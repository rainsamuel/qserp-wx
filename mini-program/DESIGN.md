# 微信小程序 UI 设计规范

## 一、设计风格

### 1.1 整体风格
- **设计语言**：简约现代，卡片式布局
- **视觉层次**：通过阴影和圆角区分内容层级
- **交互反馈**：轻触反馈，流畅动画

### 1.2 色彩系统

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色调 | 科技蓝 | `#1890FF` |
| 成功色 | 翠绿 | `#52C41A` |
| 警告色 | 琥珀 | `#FAAD14` |
| 错误色 | 珊瑚红 | `#FF4D4F` |
| 文本主色 | 深灰 | `#1F1F1F` |
| 文本次色 | 中灰 | `#666666` |
| 辅助色 | 浅灰 | `#999999` |
| 背景色 | 暖白 | `#F7F8FA` |
| 卡片背景 | 纯白 | `#FFFFFF` |
| 分割线 | 淡灰 | `#EEEEEE` |

### 1.3 字体规范

| 层级 | 用途 | 字号 | 字重 | 行高 |
|------|------|------|------|------|
| H1 | 页面标题 | 36rpx | Bold | 1.4 |
| H2 | 卡片标题 | 32rpx | Semibold | 1.4 |
| H3 | 区域标题 | 28rpx | Medium | 1.4 |
| Body | 正文内容 | 28rpx | Regular | 1.6 |
| Caption | 辅助说明 | 24rpx | Regular | 1.4 |
| Small | 标签文字 | 22rpx | Regular | 1.3 |

### 1.4 间距系统

| 名称 | 数值 | 用途 |
|------|------|------|
| xs | 8rpx | 紧凑间距 |
| sm | 16rpx | 小间距 |
| md | 24rpx | 中等间距 |
| lg | 32rpx | 大间距 |
| xl | 48rpx | 超大间距 |

### 1.5 圆角规范

| 元素 | 圆角 |
|------|------|
| 卡片 | 16rpx |
| 按钮 | 12rpx |
| 输入框 | 8rpx |
| 标签 | 6rpx |
| 头像 | 50% |

## 五、动画规范

### 5.1 页面转场
- 进入：从右向左滑入，时长 300ms
- 退出：从左向右滑出，时长 300ms
- 缓动函数：ease-out

### 5.2 弹窗动画
- 弹出：缩放 + 透明度，时长 200ms
- 背景：透明度 0 → 0.5，时长 200ms
- 缓动函数：ease-out

### 5.3 列表加载
- 下拉刷新：回弹效果
- 上拉加载：淡入效果
- 列表项：依次淡入，间隔 50ms

### 5.4 按钮反馈
- 按下：缩放 0.95，时长 100ms
- 释放：恢复 1.0，时长 100ms
- 禁用：透明度 0.6
